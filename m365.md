# Microsoft Graph API (Java 환경 활용)

이 문서는 pi에서 나눈 질의응답 기반으로 Microsoft Graph API를 Java에서 사용하는 법을 정리한 것입니다.

---

## 1. Microsoft Graph API란?
- Microsoft 365의 다양한 서비스(Outlook, Teams, OneDrive 등)에 하나의 API 엔드포인트(https://graph.microsoft.com)로 접근 가능.
- 대표 활용: 사내 메일/캘린더/Teams 연동, 조직 관리, 파일 자동화, 챗봇 등.

## 2. Java 환경에서 객체지향적으로 Graph API 사용하기
- REST API 직접 호출 대신 **Microsoft Graph Java SDK**를 통해 Java 객체, 메서드 체이닝 방식으로 편리하게 활용 가능.

### Maven 의존성
```xml
<dependency>
  <groupId>com.microsoft.graph</groupId>
  <artifactId>microsoft-graph</artifactId>
  <version>5.72.0</version>
</dependency>
```

### 인증(토큰 발급)
인증(Access Token 발급)에 MSAL4J 사용:

```xml
<dependency>
  <groupId>com.microsoft.azure</groupId>
  <artifactId>msal4j</artifactId>
  <version>1.14.3</version>
</dependency>
```

### Client Credentials Grant (App Only 방식)
```java
// 토큰 발급 (앱 전용, 사용자 인증X)
ConfidentialClientApplication app = ConfidentialClientApplication
        .builder(clientId, ClientCredentialFactory.createFromSecret(clientSecret))
        .authority("https://login.microsoftonline.com/" + tenantId)
        .build();
ClientCredentialParameters params = ClientCredentialParameters
        .builder(Collections.singleton("https://graph.microsoft.com/.default"))
        .build();
IAuthenticationResult result = app.acquireToken(params).get();
String accessToken = result.accessToken();
```

### Authorization Code Grant (사용자 인증)
```java
// 1. 브라우저에서 다음 URL로 이동하고 로그인 후 code 획득
String authUrl = app.getAuthorizationRequestUrl( ... ).toString();
// 2. 사용자가 제공한 code로 토큰 획득
AuthorizationCodeParameters params = ...;
IAuthenticationResult result = app.acquireToken(params).get();
```

## 3. App Only 방식으로 특정 사용자 메일함 접근
- **필수:** Azure 앱 등록 > 권한(Mail.Read Application permissions) + 관리자 동의 필요

```java
GraphServiceClient<Request> graphClient = GraphServiceClient
    .builder()
    .authenticationProvider(request -> request.addHeader("Authorization", "Bearer " + accessToken))
    .build();

// kim.doo@sk.com 사용자의 받은편지함 10개 메일 조회
List<Message> messages = graphClient
    .users("kim.doo@sk.com")
    .mailFolders("inbox")
    .messages()
    .buildRequest()
    .top(10)
    .get()
    .getCurrentPage();
```

## 4. 사용자 메일함 전체 폴더(받은편지함, 보낸편지함, 커스텀폴더 등) 가져오기
```java
// 최상위(루트) 폴더들 조회
List<MailFolder> folders = graphClient
    .users("kim.doo@sk.com")
    .mailFolders()
    .buildRequest()
    .get()
    .getCurrentPage();

for (MailFolder folder : folders) {
    System.out.println("폴더 이름: " + folder.displayName);
}

// 하위폴더 전체를 재귀적으로 얻으려면
void printMailFolders(GraphServiceClient<Request> graphClient, String userId, String folderId, String indent) {
    List<MailFolder> folders;
    if (folderId == null) {
        folders = graphClient.users(userId).mailFolders().buildRequest().get().getCurrentPage();
    } else {
        folders = graphClient.users(userId).mailFolders(folderId).childFolders().buildRequest().get().getCurrentPage();
    }
    for (MailFolder folder : folders) {
        System.out.println(indent + "- 폴더: " + folder.displayName);
        printMailFolders(graphClient, userId, folder.id, indent + "  ");
    }
}
// 사용: printMailFolders(graphClient, "kim.doo@sk.com", null, "");
```

---

## 5. App Only vs 사용자 인증
- App Only(Client Credentials): 앱 자체가 권한 주체. 사용자 로그인이 필요없음.
- Authorization Code: 개별 사용자의 동의/로그인 필요. (서비스형 앱 ≠ 개별 사용자 앱)
